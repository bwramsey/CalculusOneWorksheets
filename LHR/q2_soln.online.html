State the form of the limit. Determine whether the form is determinate or indeterminate. Evaluate each limit.

(a)
\(\displaystyle \lim _{x \to \infty }\left ( \ln (1 + e^{-x}) \right )^x \)
Since \(\displaystyle \lim _{x \to \infty } (1 + e^{-x}) = 1 + 0 = 1\) and \(\ln (1) = 0\), this limit is of the form \(0^{\infty }\). This is a determinate form. \(\displaystyle \lim _{x \to \infty } \left ( \ln (1 + e^{-x}) \right )^x = 0\).
(b)
\(\displaystyle \lim _{x \to \infty } \left ( \dfrac {1}{x} + 1 \right )^{\dfrac {1}{x}} \)
This limit is of the form \(1^0\), which is a determinate form.
Thus, \(\displaystyle \lim _{x \to \infty } \left ( \dfrac {1}{x} + 1 \right )^{\dfrac {1}{x}} = 1 \)
(c)
\(\displaystyle \lim _{x \to \infty } \left ( \dfrac {\arctan (x)}{x} \right ) \)
Since \(\displaystyle \lim _{x \to \infty } \arctan (x) = \dfrac {\pi }{2}\), this limit is of the form \(\dfrac {\text {\#}}{\infty }\), which is a determinate form.
Thus, \(\displaystyle \lim _{x \to \infty } \left ( \dfrac {\arctan (x)}{x} \right ) = 0\)
(d)
\(\displaystyle \lim _{x \to \infty } (x-\ln (x)) \)
This limit is of the form \(\infty - \infty \), which is an indeterminate form. We can rewrite this as:

\[\displaystyle \lim _{x \to \infty } (x-\ln (x))= \displaystyle \lim _{x \to \infty } \left (x\left (1-\dfrac {\ln (x)}{x}\right )\right )\]

We can see that \(\displaystyle \lim _{x \to \infty }\left (\dfrac {\ln (x)}{x}\right )\) is of the form \(\dfrac {\infty }{\infty }\), so we can use L’Hopital’s Rule.

\[\stackrel {L.R.}{\implies } \displaystyle \lim _{x \to \infty }\left (\dfrac {1/x}{1}\right )=\displaystyle \lim _{x \to \infty }\left (\dfrac {1}{x}\right )=0\]

Now we have:

\[\displaystyle \lim _{x \to \infty } \left (x\left (1-\dfrac {\ln (x)}{x}\right )\right )\]
This limit has the form \(\infty \cdot 1\). This is a determinate form, and, therefore,

\(\displaystyle \lim _{x \to \infty } (x-\ln (x)) =\infty \)

(e)
\(\displaystyle \lim _{x \to \infty } \left ( x \ln \left ( \dfrac {1}{x} \right ) \right ) \)
As \(x\) approaches \(\infty \), \(\dfrac {1}{x}\) approaches \(0\) from the right. So
\[\displaystyle \lim _{x \to \infty } \ln \left ( \dfrac {1}{x} \right ) = - \infty \]
Therefore, the limit in question is of the form \(\infty \cdot - \infty \), which is a determinate form.
Thus,
\[ \displaystyle \lim _{x \to \infty } \left ( x \ln \left ( \dfrac {1}{x} \right ) \right ) = - \infty \]
(f)
\(\displaystyle \lim _{x \to 0^+} (\sin (x) \cot (x) ) \)
Since \(\displaystyle \lim _{x \to 0^+} \cot (x) = \infty \), this limit is of the form \(0 \cdot \infty \). This is an indeterminate form.

Note: \(\cot (x) = \dfrac {\cos (x) }{\sin (x)}\). So

\[\displaystyle \lim _{x \to 0^+} (\sin (x) \cot (x) ) = \displaystyle \lim _{x \to 0^+} \cos (x) = 1 .\]
