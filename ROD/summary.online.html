• The Power Rule: For any real number \(n\), \(\displaystyle \ddx x^n = n x^{n-1}\).
  • The Natural Exponential Function: \(\displaystyle \ddx e^x = e^x\).
  • The Sine Function: \(\displaystyle \ddx \sin (x) = \cos (x)\).

  • The Sum Rule: If \(f(x)\) and \(g(x)\) are differentiable functions and \(c\) is a constant, then:

    • \(\displaystyle \ddx \left ( f(x) + g(x) \right ) = f'(x) + g'(x)\),
    • \(\displaystyle \ddx \left ( f(x) - g(x) \right ) = f'(x) - g'(x)\),
    • \(\displaystyle \ddx \left ( c \cdot f(x) \right ) = c \cdot f'(x)\).
