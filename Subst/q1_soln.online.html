Compute the following indefinite integrals.
(a)
\(\displaystyle \int 2t \sin (t^2) \, \d t\).
Let \(w=t^2\). Then \(\d w = 2t \, \d t\) so
\begin{align*} \int 2t \sin (t^2) \, \d t &= \int \sin (2) \, \d w\\ &= -\cos (w) + C\\ &= -\cos (t^2) + C. \end{align*}
(b)
\(\displaystyle \int \cos (x) \sqrt {\sin (x)} \, \d x\).
Set \(v = \sin (x)\). Then \(dv = \cos (x) \, dx\), so
\begin{align*} \int \cos (x) \sqrt {\sin (x)} \, \d x &= \int \sqrt {v} \, dv\\ &= \dfrac {2}{3} v^{3/2} + C\\ &= \dfrac {2}{3} (\sin (x))^{3/2} + C \end{align*}
(c)
\(\displaystyle \int \left ( 3t^2-4+\dfrac {1}{t} \right ) e^{t^3-4t+\ln (t)-9}\, \d t\).
This problem looks a lot more difficult than it really is. Let \(u = t^3-4t+\ln (t)-9\). Then \(\d u = \left ( 3t^2- 4+\dfrac {1}{t} \right ) \, \d t\), which is exactly the factor in front of the exponential.
\begin{align*} \int \left ( 3t^2-4+\dfrac {1}{t} \right ) e^{t^3-4t+\ln (t)-9}\, \d t &= \int e^u \, \d u\\ &= e^u + C\\ &= e^{t^3-4t+\ln (t)-9}+C. \end{align*}
