Find the error in the following “solution", correct the error (or errors) and evaluate the integral.

Find \(\displaystyle \int _{-\frac {\pi }{2}}^{\frac {\pi }{2}} \cos (x)\sqrt {1-\cos ^2(x)}\d x\).
"Solution":
Since \(\sin (x)=\sqrt {1-\cos ^2(x)}\), let \(u=\sin (x)\). Then \(du=\cos (x)dx\);
when \(x=-\frac {\pi }{2}\), \(u=\sin \Bigl (-\frac {\pi }{2}\Bigr )=-1\); when \(x=\frac {\pi }{2}\), \(u=\sin \Bigl (\frac {\pi }{2}\Bigr )=1\). Therefore
\(\displaystyle \int _{-\frac {\pi }{2}}^{\frac {\pi }{2}} \cos (x)\sqrt {1-\cos ^2(x)}\d x=\displaystyle \int _{-1}^{1}u \cdot du=0\),
due to symmetry (integrating an odd function over a symmetric interval, \([-1,1]\)).

Recall: \(\sin (x)\le 0\) in the fourth quadrant!

The error is that for \(-\frac {\pi }{2}\le x\le 0\)
\(\sqrt {1-\cos ^2(x)}=\sqrt {\sin ^2(x)}=|\sin (x)|=-\sin (x)\),
not“ \(\sin (x)\)", which makes the rest of the "solution" completely wrong.

In order to correct this error, we can split the integral into two integrals

\(\displaystyle \int _{-\frac {\pi }{2}}^{\frac {\pi }{2}} \cos (x)\sqrt {1-\cos ^2(x)}\d x=\displaystyle \int _{-\frac {\pi }{2}}^{0} \cos (x)\sqrt {1-\cos ^2(x)}\d x+\displaystyle \int _{0}^{\frac {\pi }{2}} \cos (x)\sqrt {1-\cos ^2(x)}\d x\)

and evaluate them separately, i.e., in the first integral we have that \(\sqrt {1-\cos ^2(x)}=-\sin (x)\) and in the second that \(\sqrt {1-\cos ^2(x)}=\sin (x)\).

Or, we can use symmetry to make the computation easier.

Namely, we “integrate" an even function over a symmetric interval \(\Bigl [-\dfrac {\pi }{2},\dfrac {\pi }{2}\Bigr ]\). Therefore

\(\displaystyle \int _{-\frac {\pi }{2}}^{\frac {\pi }{2}} \cos (x)\sqrt {1-\cos ^2(x)}\d x=2\displaystyle \int _{0}^{\frac {\pi }{2}} \cos (x)\sqrt {1-\cos ^2(x)}\d x\).

Now we use the same substitution as in the “solution" above.

\(\displaystyle \int _{-\frac {\pi }{2}}^{\frac {\pi }{2}} \cos (x)\sqrt {1-\cos ^2(x)}\d x=2\displaystyle \int _{0}^{\frac {\pi }{2}} \cos (x)\sqrt {1-\cos ^2(x)}\d x=2\displaystyle \int _{0}^{1}u \cdot du=2\Bigl [\dfrac {u^2}{2}\Bigr ]_{0}^{1}=2\cdot \dfrac {1}{2}=1\)
