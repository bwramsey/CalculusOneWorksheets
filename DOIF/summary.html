  • \(\displaystyle \ddx \left [ \cos ^{-1}(x) \right ] = \dfrac {-1}{\sqrt {1-x^2}}\)
  • \(\displaystyle \ddx \left [ \cot ^{-1}(x) \right ] = \dfrac {-1}{1+x^2}\)
  • \(\displaystyle \ddx \left [ \csc ^{-1}(x) \right ] = \dfrac {-1}{|x|\sqrt {x^2-1}}\) for \(|x| \geq 1\)
The Inverse Function Theorem If \(f\) is a differentiable function that is one-to-one near \(a\) and \(f'(a) \neq 0\), then:
(a)
\(f^{-1}(x)\) is defined for \(x\) near \(b = f(a)\),
(b)
\(f^{-1}(x)\) is differentiable for \(x\) near \(b = f(a)\),
(c)
last, but not least: \(\displaystyle \eval { \ddx f^{-1}(x) }_{x=b} = \dfrac {1}{f'(a)}\) where \(b = f(a)\).
