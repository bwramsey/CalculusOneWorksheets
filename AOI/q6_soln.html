Find all points at which the given function equals its average value on the given interval.

(a)
\(f(x) = e^x \qquad [0,4]\)
First, we need to find \(f_{\text {avg}}\):
\begin{align*} f_{\text {avg}} &= \frac {1}{4-0} \int _0^4 e^x \d x \\ &= \frac {1}{4} \eval {e^x}_0^4 \\ &= \frac {1}{4} \left ( e^4 - 1 \right ) \end{align*}

So we are looking for all values \(c \in [0,4]\) such that:

\begin{align*} f(c) &= \frac {1}{4} (e^4 - 1) \\ \Longrightarrow \quad e^c &= \frac {1}{4} (e^4 - 1) \\ \Longrightarrow \quad c &= \ln \left ( \frac {1}{4} (e^4 - 1) \right ) \end{align*}

Therefore, our answer is \(\ln \left ( \frac {1}{4} (e^4 - 1) \right )\).

(b)
\(g(x) = \frac {\pi }{4} \sin (x) \qquad [0,\pi ]\)
First, we need to find \(g_{\text {avg}}\):
\begin{align*} g_{\text {avg}} &= \frac {1}{\pi -0} \int _0^{\pi } \frac {\pi }{4} \sin (x) \d x \\ &= \frac {1}{4} \eval {-\cos (x)}_0^{\pi } \\ &= \frac {1}{4} \left ( - (-1-1) \right ) \\ &= \frac {1}{2} \end{align*}

So we are looking for all values \(c \in [0,\pi ]\) such that:

\begin{align*} &g(c) = \frac {1}{2} \\ &\Longrightarrow \quad \frac {\pi }{4} \sin (c) = \frac {1}{2} \\ &\Longrightarrow \quad \sin (c) = \frac {2}{\pi } \\ &\Longrightarrow \quad c = \arcsin \left ( \frac {2}{\pi } \right ), \pi - \arcsin \left ( \frac {2}{\pi } \right ) &\end{align*}

Therefore, our two answers are \(\arcsin \left ( \frac {2}{\pi } \right ), \pi - \arcsin \left ( \frac {2}{\pi } \right )\).
