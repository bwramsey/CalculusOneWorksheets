Consider a Riemann sum with \(n\) rectangles for the function \(f\) on the interval \([a,b]\).
Use geometry to find the limit of Riemann sums as \(n\to \infty \).
\(\lim _{n\to \infty } \sum _{k=1}^{n} f ( x_k^* ) \Delta x \) ?
(a)
\(f(x)=x\), \([0,3]\);
\(\lim _{n\to \infty } \sum _{k=1}^{n} f ( x_k^* ) \Delta x =\lim _{n\to \infty } \sum _{k=1}^{n} x_k^* \Delta x =\frac {9}{2}\),
since \(\lim _{n\to \infty } \sum _{k=1}^{n} f ( x_k^* ) \Delta x =A\), the area of the shaded region in the figure.
(b)
\(f(x)=|x|\), \([-3,3]\);
\(\lim _{n\to \infty } \sum _{k=1}^{n} f ( x_k^* ) \Delta x =\lim _{n\to \infty } \sum _{k=1}^{n} | x_k^*| \Delta x =9\),
since \(\lim _{n\to \infty } \sum _{k=1}^{n} f ( x_k^* ) \Delta x =A\), the area of the shaded region in the figure.
