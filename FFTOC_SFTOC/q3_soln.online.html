The limit of Riemann sums for a function \(f\) on the interval \([1, 5]\) is given by
\[ \lim _{n \to \infty } \sum _{k = 1}^n \left (2x_k^* + \frac {1}{x_k^*} \right ) \Delta x\mbox { on $[1, 5]$.} \]
(a)
Identify \(f\) and express the limit as a definite integral.

\[f(x)=2x+\frac {1}{x}\]

\[\int _1^5 \left ( 2x + \frac {1}{x} \right ) \d x = \lim _{n \to \infty } \sum _{k = 1}^n \left (2x_k^* + \frac {1}{x_k^*} \right ) \Delta x\]
(b)
Evaluate the limit of Riemann sums.
\[ \int _1^5 \left ( 2x + \frac {1}{x} \right ) \d x = \left (x^2 + \ln |x|\right ) \bigm |_1^5 = (25 + \ln (5)) - (1 +\ln (1)) = 24 +\ln (5) \]
