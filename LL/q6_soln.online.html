\[ h(x)=\frac {x^2-4}{4},\ 1 <x < 3 \]
\[ g(x)=x-2,\ 1 < x < 3 \]

\[ g(x) \le f(x) \le h(x),\ 1 < x < 3 \]

(b)
Evaluate the limit, or state that it does not exist. Justify your answer.
(i)
\(\displaystyle \lim _{x \to 2} f(x)\)
\(g\) and \(h\) are both continuous function since they are both polynomials so we have:
\[ \lim _{x \to 2} g(x)=g(2)=0 \]
\[ \lim _{x \to 2} h(x)=h(2)=0 \]

We have \(g(x) \le f(x) \le h(x)\) so by the squeeze theorem, \(\lim _{x \to 2} f(x)=0\) since \(g(x)\leq f(x) \leq h(x)\) with \(\lim _{x\to 2}g(x) = \lim _{x\to 2}h(x) = 0\).

(ii)
\(\displaystyle \lim _{x \to 2} \frac {f(x)+2}{x-1}\)
\[ \lim _{x \to 2}\frac {f(x)+2}{x-1}=\frac {\lim _{x \to 2}(f(x)+2)}{\lim _{x \to 2}(x-1)}\\ = \frac {0+2}{2-1}\\ = \frac {2}{1}\\ = 2 \]
(iii)
\(\displaystyle \lim _{x \to 2} g(1+e^{f(x)})\)
\[ \lim _{x \to 2} g\Bigl (1+e^{f(x)}\Bigr )= g \Bigl (\lim _{x \to 2} (1+e^{f(x)})\Bigr )= g \Bigl (\lim _{x \to 2} 1+\lim _{x \to 2}e^{f(x)})\Bigr ) =g \Bigl (1+e^{\lim _{x \to 2}f(x)}\Bigr ) \]
