Definition
If function \(f\) is continuous on interval \([a,b]\) then

\( \displaystyle \int _a^b f(x)\d x = \lim _{n \to \infty } \sum _{k = 1}^n f(x_k^*) \Delta x\)

Note 1: When \(f(x)\ge 0\), on the interval \([a,b]\), the definite integral, \( \displaystyle \int _a^b f(x)\d x\), gives
the area of the region between the graph of \(f\) and the interval \([a,b]\) on the \(x-\)axis.
Note 2: When \(f(x)<0\), on some interval in \([a,b]\), then the definite integral, \( \displaystyle \int _a^b f(x)\d x\),
gives the net area of the region between the graph of \(f\) and the interval \([a,b]\) on the \(x-\)axis.
Properties of Definite Integrals
(a) \( \displaystyle \int _a^a f(x)\d x =0\)
(b) \( \displaystyle \int _a^c f(x)\d x =\displaystyle \int _a^b f(x)\d x + \displaystyle \int _b^c f(x)\d x\)
(c) \( \displaystyle \int _a^b f(x)\d x = - \displaystyle \int _b^a f(x)\d x \)
(d) \( \displaystyle \int _a^b k\cdot f(x)\d x = k\cdot \displaystyle \int _a^b f(x)\d x \)
(e) \( \displaystyle \int _a^b ( f(x)+g(x))\d x = \displaystyle \int _a^b f(x)\d x + \displaystyle \int _a^b g(x)\d x\); \( \displaystyle \int _a^b ( f(x)-g(x))\d x = \displaystyle \int _a^b f(x)\d x - \displaystyle \int _a^b g(x)\d x\)
Note 3: If the function \(f\) is odd, i.e, if \(f(-x)=-f(x)\), for all \(x\) in \([-a,a]\), then

\( \displaystyle \int _{-a}^a f(x)\d x =0\)

Note 4: If the function \(f\) is even, i.e, if \(f(-x)=f(x)\), for all \(x\) in \([-a,a]\), then

\( \displaystyle \int _{-a}^a f(x)\d x =2\cdot \displaystyle \int _{0}^a f(x)\d x\)
