Evaluate the following integrals using symmetry arguments.
(a)
\(\int _{-\pi /4}^{\pi /4} \sin (t) \d t\)
Since the function \(f(t) = \sin (t)\) is odd, \( \int _{-\pi /4}^{\pi /4} \sin (t) \d t=0\)

We can illustrate our computation with the graph of the function \(f\), where
\(f(t)=\sin {t}\), for \(-\dfrac {\pi }{4}\leq x\leq \dfrac {\pi }{4}\).

(b)
\(\int _{-2}^2 (1+x+3x^7-x^9) \d x\)
In order to take advantage of symmetry, we will split the given polynomial into a sum of its even and odd parts. We will then integrate each part separately:
\[\int _{-2}^2 (1+x+3x^7-x^9) \d x= \int _{-2}^{2}1 \d x + \int _{-2}^{2} (x+3x^7-x^9) \d x\]

We will first integrate an even function:
\(\int _{-2}^{2} 1 \d x =2\int _{0}^{2}1\d x=2(2)=4\)

Then an odd function:
\(\int _{-2}^{2} (x+3x^7-x^9) \d x=0\)

Therefore:\(\int _{-2}^2 (1+x+3x^2-x^9) \d x=4\)
