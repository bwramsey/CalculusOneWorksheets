Find the derivatives of the following functions:
(a)
\(f(x) = x^{e^x} + 7x\)
\(f'(x) = \dfrac {d}{dx} \left (x^{e^x} \right ) + \dfrac {d}{dx}(7x) = \dfrac {d}{dx} \left (x^{e^x} \right ) + 7\). So the real problem is to find \(\dfrac {d}{dx} \left (x^{e^x} \right )\).

We will use logarithmic differentiation.

First, we take natural logarithm of both sides of the equation \(g(x)=x^{e^x}\).

\(\ln {(g(x))}=e^{x}\ln (x)\).

Now, we differentiate both sides.

\(\dfrac {g'(x)}{g(x)}=e^x\ln (x)+\dfrac {e^{x}}{x}\).

Next, we solve for \(g'(x)\).

\(g'(x)=g(x)\Bigl (e^x\ln (x)+\dfrac {e^{x}}{x}\Bigr )\).

Now, we substitute.

\(g'(x)=x^{e^x}\Bigl (e^x\ln (x)+\dfrac {e^{x}}{x}\Bigr )\).

ALTERNATIVE APPROACH

\begin{align*} \dfrac {d}{dx} \left ( x^{e^x} \right ) &= \dfrac {d}{dx} \left ( e^{\ln (x)^{e^x}} \right ) \\ &= \dfrac {d}{dx} \left ( e^{e^x \ln (x)} \right ) \\ &= e^{e^x \ln (x)} \left ( e^x \ln (x) + \frac {e^x}{x} \right ) \\ &= x^{e^x} \left ( e^x \ln (x) + \frac {e^x}{x} \right ). \end{align*}

Thus, \(f'(x) = x^{e^x} \left ( e^x \ln (x) + \frac {e^x}{x} \right ) + 7\).

We multiply by \(g(x)\).

\(g'(x) = g(x)\Bigl (4x^3\sec (x^4)\tan (x^4)\ln {(\ln (x) + 9)}+\dfrac {\sec (x^4)}{x(\ln (x) + 9)}\Bigr )\)

We substitute.

\(g'(x) =(\ln (x) + 9)^{\sec (x^4)}\Bigl (4x^3\sec (x^4)\tan (x^4)\ln {(\ln (x) + 9)}+\dfrac {\sec (x^4)}{x(\ln (x) + 9)}\Bigr )\)

(d)
\(h(x) = \frac {(x^2 - 7)^5}{\cos ^7(x^2 - 5)}\)
Since \(h(x)\) changes sign on its domain, we write :
\begin{align*} \ln |h(x)| &= \ln \left ( \frac {|x^2 - 7|^5}{\ |cos^7(x^2 - 5)|}\right ) \\ &= 5 \cdot \ln (|x^2 - 7|) - 7 \cdot \ln (|\cos (x^2-5)|) \end{align*}

Differentiate both sides with respect to \(x\), (explanation given on the next page):
\( \dfrac {h'(x)}{h(x)} = 5 \dfrac {2x}{x^2 - 7} - 7 \dfrac {-\sin (x^2-5)2x}{\cos (x^2 - 5)} \)
\( h'(x) =h(x)\bigl ( 5 \dfrac {2x}{x^2 - 7} - 7 \dfrac {-\sin (x^2-5)2x}{\cos (x^2 - 5)} \bigr )=\)
\( =\frac {(x^2 - 7)^5}{\cos ^7(x^2 - 5)}\bigl ( \dfrac {10x}{x^2 - 7} + \dfrac {14x\sin (x^2-5)}{\cos (x^2 - 5)} \bigr )=\)
\( =\frac {(x^2 - 7)^4}{\cos ^7(x^2 - 5)}\bigl ( 10x + 14x(x^2-7) \tan (x^2-5) \bigr )\)

EXPLANATION: The function \(h(x)\) assumes negative values on some intervals. On those intervals

\(\bigl (\ln (|h(x)|)\bigr )'=\bigl (\ln (-h(x))\bigr )'=\dfrac {-h'(x)}{-h(x)}=\dfrac {h'(x)}{h(x)}\),
