Find all real numbers \(x\) which satisfy each of the following equations.

(a)
\(\log _x(25) = 2\).
Recall that, by definition of the inverse to an exponential function,
\[ \log _b(x) = y \iff x = b^y. \]
Using this relationship we have \(\log _x(25) = 2 \iff x^2 = 25\). Therefore
\begin{align*} x^2 = 25 &\implies x = \pm 5,\\ &\implies x = 5 \hspace {1em} \mbox {(base of log is always $>0$)}. \end{align*}

Therefore \(x = 5\) is the only solution to \(\log _x(25) = 2\).

(b)
\(7^x = 15\)
Similar to the previous problem,
\[ \log _b(x) = y \iff x = b^y . \]
Using this relationship we have \(7^x = 15 \iff x = \log _{7}(15)\). Therefore \(x = \log _7(15)\) is the only solution to \(7^x = 15\).
(c)
\(\ln (x) + 1 = 0\).
Similar to the previous two problems we’ll use the relationship
\[ \ln (x) = y \iff x = e^y. \]
Before applying this relationship we perform a bit of algebra first:
\[ \ln (x) + 1 = 0 \implies \ln (x) = -1. \]
Now we have \(\ln (x) = -1 \iff x = e^{-1}\). Therefore \(x = e^{-1} (= 1/e)\) is the only solution to \(\ln (x) + 1 = 0\).
