Basic properties of the natural logarithm:

  • \(\displaystyle \ln \left ( yz \right ) = \ln (y) + \ln (z)\)
  • \(\displaystyle \ln \left ( \dfrac {y}{z} \right ) = \ln (y) - \ln (z)\)
  • \(\displaystyle \ln \left ( y^z \right ) = z\ln (y)\)
  • For any function \(g\): \(\displaystyle \ln ( e^{g(x)} ) = g(x)\)
  • \(\displaystyle \dfrac {d}{dx} \left ( \ln (f(x) \right ) = \dfrac {f'(x)}{f(x)}\).
