Without using a calculator, determine if the statement
\[ \cos ^{-1}\bigl (\cos (7\pi /6)\bigr ) = 7\pi /6 \]
is true or false.
This statement is false: the correct statement is \(\cos ^{-1}\bigl (\cos (7\pi /6)\bigr ) = 5\pi /6\). (Why?)

Spoiler Alert: the cosine function is not invertible since its graph fails the horizontal line test.
